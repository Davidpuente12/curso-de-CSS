El diseño responsivo (Responsive Design) consiste en un conjunto de herramientas para que tu sitio se vea bien en varias medidas de pantalla, esto incluye imágenes, tipografía, internacionalización de la página y entre otros. En la actualidad, la mayoría de sitios web son visitados desde un celular, por lo que asegurarse que nuestro sitio sea responsivo para cualquier dispositivo es fundamental para optimizar las ganancias.

Estrategias de diseño
Mobile first Enfoque en Dispositivos moviles y luego escalamos a otros dispositivos
Desktop first Enfoque en Dispositivos de escritorio y luego escalamos a otros dispositivos

Diseño con porcentajes

El primer paso para crear un diseño que se adapte correctamente es comenzar con las unidades de medidades como los porcentajes. siendo estas relativas a contenedor padre nos aseguramos que el navegador tome estas medidas. Es necesario establecer medidas al contenedor padre.

Tamaños maximos y minimos

Para tener mayor control de los tamaños es ideal establecer sus valores maximos y minimos, asi nos aseguramos que el contenido no se deforme si la pantalla es mas grande o mas pequeña de lo habitual. Las propiedadse que se usan son max-width | min-width.

Viewport (Region visible)

Este paso es muy importante, se trata de preparar al navegador para el responsive, indicandole que el ancho de pantalla sera el ancho del disposito, para que el viewport se adapte consecuentemente. lo haremos mediante el siguiente codigo.

<meta name = "viewport" content = "width=device-width, initial-scale=1">

Breack Points

Los puntos de interrupcion permiten cambiar el diseño de los elementos predefinidos. por ejemplo cuando tenemos 3 columnas en una computadora, y cuando se redimensiona la pantalla a un telefono, queremos que el elemento que los contiene se rompa recolocando los elementos uno abajo del otro.

Media Queries

Nos permiten aplicar condiciones al diseño de nuestra pagina, en las que si se cumple la condicion se aplican los estilos que determinemos y en caso contrario no se aplicarian. Esto sirve para establecer el layout del sitio web para diferentes tipos de pantalla: escritorio, tablets y celulares. Se deben usar al final del codigo css.

Propiedad Descripcion
max-width / max-height establece un rango máximo para cierto comportamiento.
min-width / min-height establece un rango mínimo para cierto comportamiento.

@media

La regla media es la herramienta perfecta para crear diseños responsivos que se adapten automaticamente a caracteristicas del dispositivo del usuario como tamaños de pantallas , lector de voz, orientacion, resolucion, etc. La estructura de una media querie consiste en empezar con @media, seguido del tipo de la media querie estableciendo un rango, envolviendo las reglas CSS dentro de ese rango.

( )
Regla Descripcion
@media (condicion) Si se cumple la condicion se aplican los estilos en su interior
@media not (condicion) Niega la condicion y aplica los estilos cuando es falsa
@media only (condicion) Filtra navegadores antiguos para que nos se apliquen los estilos
@media (condicion) y (condicion) Si se cumplen ambas condiciones se aplican los estilos
Tipo de medio Descripcion
all Todos los dispositivos o medios. Por defecto
screen Monitores o pantallas de ordenador. Mas comun
print Documentos de medios impresos o pantallas de previsualizacion de impresion
Condicion Descripcion
width > size | min-width : size si el ancho es mayor al size entra la condicion
width < size | max-width : size si el ancho es menor al size entra la condicion
En las condiciones podemos usar los operadores < = > o establecer con los parametros max y min.

En este cuadro Responsivo todas las medidas son relativas, con tamaños maximos y minimos para que no se deforme con: max/min-width. Patrones de Diseño

Mustly Fluid

Este patron organiza el layout con diseños fluidos y centrados. En pantallas pequeñas los bloques forman una sola colunma vertical y a medida que va creciendo acomoda los bloques en fila uno junto al otro de acuerdo a su ancho disponible y sin romper el layut original.

  • ✅ Los elementos tienen anchos % que junto con flexbox y wrap les permite adaptarse al ancho disponible.
  • 📐 El contenedor principal tiene un ancho máximo fijo en pantallas grandes, para evitar que el contenido se extienda.
  • 📱 En pantallas pequeñas, los elementos se apilan verticalmente y ocupan el 100% del ancho.

Layout Shifter

Su objetivo es reorganizar completamente el layout segun el tamaño de la pantalla, moviendo bloques de contenido entre contenedores o cambiando su orden visual.

  • ✅ Los elementos usan Flexbox y order para cambiar el diseño de forma inteligente.
  • 📐 Reorganiza los bloques en horizontal o en nuevas posiciones cuando el ancho aumenta.
  • 📱 En pantallas pequeñas, los elementos se apilan verticalmente y ocupan el 100% del ancho.

Column Drop

Este patron consiste en que cada bloque del contenido que esta verticalmente en una sola columna en pantallas pequeñas, se vayan desplegando horizontalmente en la primera fila segun vaya creciendo la pantalla del dispositivo, ocupando el ancho disponible. para eso utilizamos Flexbox wrap y order.

  • ✅ Los elementos usan Flexbox y order para cambiar el diseño de forma inteligente.
  • 📐 Reorganiza los bloques en horizontal ocupando todo el ancho del viewport.
  • 📱 En pantallas pequeñas, los elementos se apilan verticalmente y ocupan el 100% del ancho.

Selecciona el patron que deseas ver, puedes aumentar el ancho de la ventana que te aparecera para ver como los elementos se organizan de acuerdo a su patron.

Media Queries en html

La velocidad de carga de una web influye enormemente en la experiencia de usuario. Cuando nuestro proyecto crece considerablemente, es vital distinguir qué elementos del CSS deben cargarse inmediatamente y cuáles pueden hacerlo posteriormente. Aplicando técnicas específicas, podemos garantizar una carga más rápida y eficiente.

Otra forma de aplicar los media queries es utilizando la etiqueta <link> con el atributo media para establecer la condicion. De este modo podemos establecer varias hojas de estilo las cuales se aplicarian de acuerdo a las medidas establecidas por la condicion. al momento de cargar los archivo css le da prioridad al mas compatible con la pantalla, haciendo asi el tiempo de carga mas fluido, y esta es la razon de que sea el mas recomendado.

link rel="stylesheet" href="mobile.css" media="(max-width: 640px)"
link rel="stylesheet" href="desktop.css" media="(min-width: 1280px)"
link rel= "..." href="tablet.css" media="(min-width: 640px)"and"(max-width: 1280px)"

Carga diferida

La carga diferida (deferred loading) implica priorizar la visualización del contenido esencial en el menor tiempo posible, retrasando la carga de elementos secundarios. Al cargar primero los estilos críticos y posponer pocos instantes los menos importantes, se ayuda al usuario a interactuar rápidamente con el sitio.

Los estilos críticos son aquellos elementos visuales fundamentales para la percepción inicial del usuario:

  • Tipografía del contenido principal.
  • Colores y disposición inicial.
  • Elementos que aparecen inmediatamente en pantalla.

Por otro lado, los estilos no críticos afectan elementos complementarios que no inciden directamente en la primera impresión visual:

  • Efectos visuales secundarios.
  • Estilos en secciones inferiores o posteriores.

Para retrasar la carga del CSS no crítico hasta que los elementos principales ya estén listos, se utiliza la siguiente estructura:

<link
  rel="stylesheet"
  href =   "estilos-no-criticos.css"
  media="print"
  onload = "this.media='all'">

La implementación de CSS diferido, aunque resulte casi imperceptible en proyectos pequeños, toma gran valor cuando nuestra web crece. Reducir la carga inicial incrementa notoriamente el desempeño percibido por el usuario

Carga diferida de estilos con Javascript

Lazy loading consiste en cargar recursos como hojas de estilo CSS cuando realmente son necesarios, generalmente en respuesta a una interacción del usuario. Esto ayuda a disminuir el consumo innecesario de recursos, mejorando la velocidad inicial y rendimiento general del sitio web.

Para implementar esta técnica, seguimos estos pasos básicos en JavaScript:

  • Identificar elemento disparador: seleccionamos un botón o evento específico que active la carga secundaria de estilos.
  • Crear el elemento link dinámicamente
  • Insertar en el head del documento
  • Evitar recargas múltiples: deshabilitamos el disparador luego de usado, evitando duplicidad en la carga

document.getElementById ('boton').addEventListener('click', function() {
  let link = document.createElement('link');
  link.rel = 'stylesheet';
  link.href = 'estilos-no-criticos.css';
  document.head.appendChild(link);
  this.disabled = true;
});
