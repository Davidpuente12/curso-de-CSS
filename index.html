CSS (Cascading Style Sheets) es un lenguaje de estilo utilizado para describir la presentación de un documento HTML. Básicamente, permite diseñar y dar formato a una página web, controlando aspectos como colores, fuentes, espaciado, tamaños y diseño de los elementos.

Existen tres formas de aplicar estilos: 1. como atributo inline en la propia etiqueta, 2. dentro de la etiqueta style en el head, 3. mediante una hoja de estilos externa enlazada con link. La recomendación práctica es trabajar con un archivo externo.

funciona separando el contenido y diseño con html estructuramos la página, mientras que CSS se encarga de su apariencia, los estilos se aplican mediante selectores, propiedades y valores que pueden heredarse y aplicarse de manera jerárquica

Declaraciónes

Una declaración de CSS es un bloque que especifica el conjunto de estilos que se añadirán a un elemento HTML. Su estructura contiene dos elementos principales:

  • Selector: define el elemento o conjunto de elementos a los cuales se añadirán los estilos.
  • Propiedad: es el nombre del estilo de CSS.
  • Valor: es el valor que tomará la propiedad.
section{ margin: auto 10px; }

Selectores básicos

Selector de tipo

Selecciona todos los elementos que coincidan con el nombre de la etiqueta HTML.

Selector de clase

Selecciona todos los elementos que coincidan con las etiquetas HTML que contengan el atributo class. Para seleccionar estos elementos, se empieza por un punto . y seguido el valor exacto del atributo class de la etiqueta. Puede ser cualquier valor que desees colocar.

Selector de identificador único

Selecciona el único elemento que coincida con la etiqueta HTML que contenga el atributo id. Solo puede existir un valor id para todo el documento.Para seleccionar el elemento, se empieza por el símbolo de hashtag # y seguido el valor exacto del atributo id de la etiqueta. Puede ser cualquier valor que desees colocar.

Selector de atributo

Selecciona los elementos que coincidan con la etiqueta HTML que contenga el atributo y valor especificado.Para seleccionar los elementos, se empieza por el nombre de la etiqueta, seguido de corchetes [] que contiene el atributo y valor especificado.

Selector universal

Selecciona todos los elementos del documento mediante un asterisco.

HTML CSS
<div> div { afecta todos los div del documento }
<div class = "red"> .red { afecta a los div con la clase }
<button id = "unico"> .unico { afecta solo la etiqueta con el id unico }
<a href = "https://platzi.com"> a [href = "https://platzi.com"] { afecta solo los enlaces con el mismo valor }
* { afecta a todos los elementos de la pagina.}

Selectores combinados

Combinador de descendientes

Selecciona todos los elementos del selector de la derecha (p) que son hijos del selector de la izquierda (div), independientemente de la profundidad de anidacion. Estos selectores están separados por un espacio.

div p{ afecta todos los hijos <p> del <div>}
.container img{ Todos los hijos <img> de la clase "container" }

Combinador de hijo directo

Selecciona todos los elementos del selector de la derecha que son hijos directos del selector de la izquierda. Estos selectores están separados por >.

div > p{ todos los hijos directos <p> del <div>}
.container > img{ Todos los hijos directos <img> de la clase "container" }

Combinador de elemento adyacente

Selecciona todos los elementos del selector de la derecha que están adyacente al selector de la izquierda. Estos selectores están separados por +. elemento + adyacente {Elementos adyacentes}

div + p{ todos los <p> adyacentes a <div>}
.container + img{ Todos los <img> adyacentes a la clase "container" }

Adyacente significa que comparten el mismo padre y está situado inmediatamente hacia abajo de otro elemento. Por ejemplo, en el siguiente código, <div> está adyacente a <h1> y <p> está adyacente a <div>. Sin embargo, <h1> no está adyacente a <div> y <div> no está adyacente a <p>.

Combinador general de hermanos

Selecciona todos los elementos del selector de la derecha que son hermanos del selector de la izquierda. Estos selectores están separados por ~ (Alt 126) elemento ~ hermanos. Hermanos significa que comparten el mismo padre y están situados hacia abajo de otro elemento

div ~ p{ todos los <p> hermanos de <div>}
.container ~ img{ Todos los <img> hermanos a la clase "container" }

Cascada y Especificidad

La cascada es el concepto que determina qué estilos se colocan sobre otros, priorizando a aquellos que se encuentren más abajo del código. Recordarás que CSS es la abreviación de Cascade Style Sheets, que traducido es hojas de estilos en Cascada.

Importancia: El navegador carga estilos de distintas fuentes. Primero aplica los estilos predeterminados del usuario (navegador), luego los estilos escritos por los desarrolladores, y por último aplica aquellos con la etiqueta !important al final de una declaración.

¿Qué es especificidad?

La especificidad consiste en dar un valor a una regla CSS sobre qué tan específico es el estilo, esto para que los navegadores puedan saber qué estilos aplicar sobre otros, independientemente de dónde se encuentren en el código. El estilo se aplicará donde la especificidad sea mayor. Existen 6 tipos de especificidad con su respectivo valor, donde (uno) es la cantidad de estilos que lo contienen.

SelectoresEspecificidad
!important1,0,0,0,0
Inline styles (estilos en linea)0,1,0,0,0
#id (identificadores)0,0,1,0,0
.class (clases)0,0,0,1,0
Etiquetas0,0,0,0,1
* Selector Universal 0,0,0,0,0

!important

La palabra reservada !important es un valor de toda propiedad CSS que provee una especificidad de 10000, por lo que se aplicará ante otros estilos. Esto es una mala práctica y no deberías utilizarlo.

<h1 style = "color: red;" !important>Especificidad = 10000 </h1>

Estilos en línea

Los estilos en línea son las propiedades CSS escritas en el HTML a través de la propiedad/atributo style de toda etiqueta. También es una mala práctica y debes evitarlo.

<h1 style = "color: blue;">Especificidad = 1000 </h1>

Especificidad en selectores

Los selectores de tipo ID son más específicos que las clases, atributos y pseudoclases. Estas últimas son más específicas que los elementos y pseudoelementos. El selector universal tiene una especificidad de 0. Los selectores combinadores suman la especificidad de cada selector basico. Si utilizas Visual Studio y mantienes el mouse sobre el selector, te mostrará la especificidad total.

¿Cómo afectan la especificidad y el orden de las reglas CSS?

  • Importancia: Primero verifica si hay un estilo con !important.
  • Estilo Embebido: Luego considera los estilos inline.
  • Especificidad: Revisa las reglas según las características de especificidad (qué tan detallado es el selector).
  • Orden de declaración: Las reglas declaradas más abajo en el archivo CSS tienen preferencia.

Tipos de Posicionamiento

El posicionamiento en CSS consiste en cómo un elemento se situará, con respecto a su elemento padre y al flujo normal del documento. El flujo normal del documento es el orden de los elementos establecidos en el HTML.

position

La propiedad position en CSS define cómo se posiciona un elemento en el flujo documento y cómo se comporta respecto a sus cordenadas, tiene subpropiedades de posicion: top right bottom left, estas sirven para mover el elemento con respecto a su padre.

Valor Descripcion
static Valor por defecto. El elemento se posiciona según el flujo normal del documento. No se aplican top, right, bottom, ni left.
relative El elemento se posiciona en relación a su posición original. Puedes moverlo con top, left, etc., sin sacarlo del flujo del documento.
absolute El elemento se posiciona respecto al contenedor más cercano que no tenga position: static. Se elimina del flujo del documento.
fixed Similar a absolute, pero se posiciona respecto a la ventana del navegador. No se mueve al hacer scroll.
sticky El elemento actúa como relative hasta que se alcanza un umbral de scroll, y luego se comporta como fixed. Ideal para encabezados pegajosos.

Posición estática La posición static es el valor por defecto de todo elemento HTML, consiste en respetar el flujo normal del documento donde las propiedades de posición no pueden ser establecidas.

Posición relativa mantiene el elemento dentro del flujo normal del documento, pero permite ajustar su posición usando top, left, right o bottom. El elemento sigue ocupando su espacio original en la pagina pero puedes modificar su ubicación. Es util para mover elementos sin alterar el diseño de otros.

Posición absoluta consiste en quitar al elemento del flujo normal del documento, esto significa que el elemento se situa con respecto a su contenedor mas cercano que tenga una propiedad "position" distinta a static. Si no hay un contenedor con relative, absolute o fixed, el elemento se posiciona en relación con el <html>.

Posición fija La posición fixed consiste en quitar al elemento del flujo normal del documento y fijarlo en un lugar donde quedara fijo en la pantalla al hacer scroll; donde las propiedades de posición sí pueden ser establecidas.

Posición variable fija La posición sticky consiste en quitar al elemento del flujo normal del documento y fijarlo en un lugar mientras su contenedor sea visible; donde las propiedades de posición sí pueden ser establecidas. Eso significa que permite que un elemento se comporte como relative hasta que se alcance un determinado punto de desplazamiento, momento en el cual se "pega" a su posición y actúa como fixed. Es útil para mantener elementos visibles mientras el usuario hace scroll.

Variables Globales

Las CSS Custom Properties (conocidas como variables CSS) son un mecanismo de CSS que permite dar un valor personalizado a las propiedades CSS. El objetivo principal es evitar escribir múltiples veces un mismo valor, y en su lugar, ponerle un nombre más lógico, semántico y fácil de recordar, que hará referencia al valor real. De esta forma será mucho más legible y más fácil de mantener.

Crear y usar variables en CSS

Para declarar variables globales utilizaremos el selector / pseudo-clase :root ya que tiene mayor especificidad y es global. la sintaxis es: dos guiones (--) como prefijo al nombre que vamos a utilizar seguido del valor. Esta pseudoclase hace referencia al elemento raíz del documento <html>.

Para usarlas haremos uso de la funcion var(), que indica que se usara una variable global, y recibe como parametro el nombre de la variable que ya declaramos. Tambien podemos agregar un segundo parametro que puede ser otra variable o el valor por defecto de la propiedad.

Tambien podemos declarar variables globales en otros selectores, pero solo funcionara dentro del mismo, su principal ventaja seria la de poder sobreescribir una varibale global ya definida, esto podria ser util si queremos que los estilos sean diferentes para el elemento al que se aplica.

:root {
  --letra-amarilla: yellow
}

h2 {
  color: var( --letra-amarilla, segundo parametro(opcional) )
}
Las custom properties se suelen agrupar en las primeras líneas de un bloque CSS, separándolas por una línea en blanco de las demás propiedades. Esto facilita la lectura del código.

¿Qué es la herencia en CSS?

La herencia en CSS se refiere al fenómeno por el cual algunos estilos establecidos en un elemento HTML se transmiten automáticamente a sus elementos hijos. Por ejemplo, al definir un tamaño de fuente en la etiqueta , ese tamaño puede propagar a etiquetas como <p> o <span> que no tengan un tamaño de fuente definido explícitamente.

  • Propiedades herederas comunes: tamaño de fuente (font-size), color de texto (color).
  • Propiedades no herederas: márgenes (margin), posición (position), anchura (width).
            html{
                font-size: 75%; /* Aplica un 75% del tamaño de fuente por defecto */
                font-family: Verdana, sans-serif; /* Cambia la fuente a Verdana */
            }

En el ejemplo anterior, se establece un tamaño de fuente del 75% para la etiqueta . Esto significa que todos los elementos de texto dentro del documento heredarán este tamaño de fuente, a menos que se defina un tamaño específico en ellos.

¿Cómo controlar o romper la herencia?

En CSS, puedes decidir explícitamente cuándo deseas que un elemento herede propiedades. Mediante el uso de la propiedad inherit, puedes forzar a un elemento a que tome el estilo de su elemento padre, aunque no lo haga por defecto.

            h1{
                font-size: inherit; /* Hereda el tamaño del padre más cercano con tamaño definido */
            }
