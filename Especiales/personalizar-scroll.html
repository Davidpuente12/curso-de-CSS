Personalizar Scrolls

Las propiedades estándar para dar estilo a las barras de scroll en CSS son scrollbar-width y scrollbar-color. Además, en navegadores basados en WebKit (Chrome, Safari, Edge), se usan pseudo-elementos como ::-webkit-scrollbar, ::-webkit-scrollbar-thumb, y ::-webkit-scrollbar-track para un control más detallado.

scrollbar-width

Permite controlar el grosor de las barras de desplazamiento en contenedores con overflow. Es una propiedad estándar soportada principalmente en Firefox, y se aplica al elemento contenedor que tiene scroll.

Valor Descripción
auto Grosor por defecto del navegador.
thin Scroll más delgado que el estándar.
none Oculta la barra de scroll (aunque el contenido sigue siendo desplazable con mouse/teclado).

scrollbar-color

Permite personalizar los colores de las barras de desplazamiento en navegadores que la soportan (principalmente Firefox). Se aplica al elemento contenedor que tiene scroll y define dos colores

  • Thumb → la parte que se arrastra.
  • Track → el fondo sobre el cual se mueve el thumb.

scrollbar-color: color-thumb / color-track;

#contenedor {
  width: 80%;
  height: 100px;
  overflow: auto;
  scrollbar-width: thin;
  scrollbar-color: var(--doger) #303030;
}

Pseudo-elementos WebKit

Los pseudo-elementos WebKit son extensiones específicas de navegadores basados en WebKit/Blink (como Chrome, Safari y Edge) que permiten personalizar las barras de desplazamiento. No forman parte del estándar CSS oficial, pero son ampliamente usados porque ofrecen un control detallado sobre cada parte del scroll.

Pseudo-elemento Función Ejemplo
::-webkit-scrollbar Área completa de la barra (ancho/alto). width: 12px;
::-webkit-scrollbar-thumb El pulgar que se arrastra. background: green;
::-webkit-scrollbar-track El fondo de la barra. background: lightgray;
::-webkit-scrollbar-corner La esquina donde se cruzan scrollbars. background: #ddd;

solo ::-webkit-scrollbar cambia el tamaño, pero para que se note visualmente necesitas también ::-webkit-scrollbar-thumb y ::-webkit-scrollbar-track.

#contenedor {
  width: 80%;
  height: 100px;
  overflow: auto;
}

#contenedor::-webkit-scrollbar {
  width: 10px;
}

#contenedor::-webkit-scrollbar-thumb {
  background: var(--doger);
  border-radius: 10px;
}

#contenedor::-webkit-scrollbar-track {
  background: rgb(50, 50, 50);
}

Consideraciones: Cuando se modifica el ancho/alto de la barra, el motor de renderizado elimina las flechas porque no están contempladas en la implementación moderna del scrollbar.
