El background en CSS es una herramienta versátil que permite dar estilo visual al área detrás del contenido de un elemento. Con ella puedes aplicar colores sólidos, imágenes decorativas, patrones repetidos o incluso fondos dinámicos que se adaptan al tamaño de la pantalla.

Background

La propiedad background en CSS es un shorthand (atajo) que permite definir en una sola línea múltiples aspectos del fondo de un elemento, como color, imagen, posición, repetición y más. es una propiedad abreviada que combina varias propiedades relacionadas con el fondo en una sola declaración. Se aplica a todos los elementos HTML y no se hereda automáticamente. Tambien permite varias imagenes usando comas para separar.

background: color, image, position / size, repeat, atachment, clip
/* Atajo completo */

background: blue url("imagen.jpg") 0 0 / 150px space scroll padding-box padding-box

/* Atajo múltiple */

background:
  url("primer-plano.jpg") center center / cover,
  blue url("imagen.jpg") 0 0 / 150px space scroll padding-box padding-box;

Ten en cuenta que el parámetro size es opcional. De indicar el carácter /, la propiedad background se esperará el valor background-size a continuación de background-position. Si no necesitamos algún valor, simplemente podemos omitirlo
Familia de propiedades background
Subpropiedad Definición breve
background-color Define el color sólido de fondo de un elemento.
background-image Establece una o varias imágenes como fondo.
background-position Indica la ubicación inicial de la imagen de fondo.
background-size Controla el tamaño de la imagen de fondo.
background-repeat Determina si la imagen se repite o no.
background-attachment Define si el fondo se desplaza con el contenido o permanece fijo.
background-origin Especifica el área de referencia para colocar el fondo.
background-clip Indica hasta dónde se extiende el fondo dentro del elemento.

background-color

La propiedad background-color en CSS se utiliza para definir el color de fondo de un elemento HTML. Es una de las subpropiedades más simples y directas del conjunto background, y su función es rellenar el área detrás del contenido con un color sólido, ocupando toda su area de caja.

background-image

La propiedad background-image en CSS se utiliza para establecer una o varias imágenes como fondo de un elemento HTML. Es una de las subpropiedades del conjunto background, y su función es mostrar una imagen detrás del contenido del elemento.

  • Acepta URLs de imágenes (url("imagen.png")).
  • Puede usar gradientes CSS como fondo (linear-gradient(...), radial-gradient(...)).
  • Permite múltiples imágenes separadas por comas.
  • Se combina con otras subpropiedades como background-position, background-size y background-repeat.
Valor Descripción breve
none Indica que no se usará ninguna imagen de fondo. (por defecto)
url() Es una funcion que permite establecer una imagen como fondo mediante una ruta local o externa.
linear-gradient() Genera un gradiente lineal como fondo.
radial-gradient() Genera un gradiente radial como fondo.
conic-gradient() Genera un gradiente cónico como fondo.

background-position

Se utiliza para definir la posición inicial de la imagen de fondo dentro de un elemento. Su función principal es controlar dónde se coloca la imagen (por ejemplo, centrada, en la esquina superior izquierda, en la parte inferior derecha, etc.), antes de que se aplique cualquier repetición o ajuste de tamaño.

  • Permite alinear la imagen en posiciones predefinidas (ej. top, center, bottom)
  • Acepta valores en palabras clave, porcentajes o unidades (px, em, etc.).
  • Se puede usar para colocar la imagen en cualquier punto del contenedor.
  • En combinación con background-size, ayuda a crear diseños más precisos y responsivos.
Valor Descripción breve
left top Coloca la imagen en la esquina superior izquierda.
left center Coloca la imagen en el centro del lado izquierdo.
left bottom Coloca la imagen en la esquina inferior izquierda.
right top Coloca la imagen en la esquina superior derecha.
right center Coloca la imagen en el centro del lado derecho.
right bottom Coloca la imagen en la esquina inferior derecha.
center top Coloca la imagen centrada en la parte superior.
center center Coloca la imagen exactamente en el centro.
center bottom Coloca la imagen centrada en la parte inferior.
valores en px o % Permite ubicar la imagen en coordenadas específicas.

background-size

Se utiliza para definir el tamaño de la imagen de fondo dentro de un elemento. Su función principal es controlar cómo se escala o ajusta la imagen en relación con el área del contenedor, permitiendo que se adapte de forma precisa al diseño.

Valor Descripción breve
auto Usa el tamaño original de la imagen.
cover Escala el ancho de la imagen de fondo al ancho del elemento., aunque se recorte.
contain Escala el alto de la imagen de fondo al alto del elemento.
valores en px Define un tamaño fijo en píxeles.
valores en % Escala la imagen en proporción al tamaño del contenedor.
dos valores (ancho alto) Permite definir el ancho y el alto de la imagen por separado. (background-size: 200px 100px;)

background-repeat

La propiedad background-repeat en CSS se utiliza para definir cómo se repite una imagen de fondo (cuando la imagen es pequeña) dentro de un elemento. Su función principal es controlar si la imagen se repite en el eje horizontal, vertical, en ambos, o si no se repite en absoluto.

Valor Descripción breve
repeat La imagen se repite en ambos ejes (horizontal y vertical). (por defecto)
repeat-x La imagen se repite solo en el eje horizontal.
repeat-y La imagen se repite solo en el eje vertical.
no-repeat La imagen se muestra una sola vez, sin repetición.
space La imagen se repite dejando espacios iguales entre copias.
round La imagen se escala para encajar y repetirse sin cortar.
.container {
  background-color: #222;
  background-image: url("../img/imagenDeLaTierra.jpg");
  background-repeat: repeat ; no-repeat ;
  background-size: auto; contain; cover;
  background-position: left; center; right;
  width: 600px;
  height: 300px;
}

backdrop-filter

La propiedad backdrop-filter en CSS permite aplicar efectos gráficos (como desenfoque, brillo, contraste, sepia, etc.) al área que está detrás de un elemento, siempre que dicho elemento tenga un fondo parcialmente transparente. Es muy usada para crear efectos de vidrio esmerilado o interfaces con estilo “blur” moderno.

  • backdrop-filter aplica filtros visuales al backdrop (todo lo que se ve detrás del elemento).
  • Requiere que el elemento tenga transparencia (opacity < 1 o background-color con alfa).
Valor Descripción
blur(length) Aplica un desenfoque al fondo.
brightness(<porcentaje>) Ajusta el brillo del fondo.
contrast(<porcentaje>) Modifica el contraste del fondo.
grayscale(<porcentaje>) Convierte el fondo a escala de grises.
sepia(<porcentaje>) Aplica un efecto sepia al fondo.
invert(<porcentaje>) Invierte los colores del fondo.
hue-rotate(<grados>) Rota el matiz de los colores.
saturate(<porcentaje>) Aumenta o reduce la saturación.
drop-shadow(<valores>) Aplica una sombra al fondo.
none Sin efecto, valor por defecto.

Estos valores se pueden combinar:

backdrop-filter: blur(8px) brightness(70%) contrast(120%);

.container {
  background-color: rgba(255, 255, 255, 0.2);
  backdrop-filter: blur(5px); brightness(150%) grayscale(50%)
}

Funcion blur()

El valor blur() dentro de backdrop-filter es uno de los más usados porque crea el famoso efecto de “vidrio esmerilado” o “fondo borroso” detrás de un elemento. El nivel de desenfoque se controla con una longitud(px, em, rem). El número representa el radio de desenfoque gaussiano, es decir, cuántos píxeles se mezclan entre sí. Cuanto mayor sea el valor, más difuso se verá el fondo.

Valor Efecto esperado
blur(0px) Sin desenfoque, fondo nítido.
blur(2px) Desenfoque leve, detalles aún visibles.
blur(10px) Fondo claramente borroso, se pierde definición.
blur(30px) Fondo muy difuso, formas apenas reconocibles.
blur(100px) Fondo completamente lavado, casi uniforme.

no hay un límite máximo estricto: puedes usar valores muy altos, pero en la práctica lo más común es trabajar entre 2px y 20px para lograr un efecto estético sin comprometer demasiado el rendimiento.

mix-blend-mode

La propiedad mix-blend-mode en CSS define cómo el contenido de un elemento se mezcla con el fondo y los elementos que están detrás de él, permitiendo efectos similares a los modos de fusión de Photoshop o GIMP. Es muy útil para crear composiciones visuales dinámicas, juegos de color y efectos artísticos en interfaces web.

  • mix-blend-mode especifica el modo de fusión que se aplicará entre el contenido del elemento y su fondo/padre.
  • Funciona de manera similar a los blend modes en programas de edición de imágenes.
  • El valor por defecto es normal (sin mezcla).
Valor Descripción
normal Sin mezcla, se muestra tal cual.
multiply Oscurece combinando colores, como superposición de tintas.
screen Aclara la imagen, como proyección de luz.
overlay Combina multiply y screen según el brillo.
darken Muestra los tonos más oscuros entre fondo y elemento.
lighten Muestra los tonos más claros entre fondo y elemento.
color-dodge Aclara intensamente las áreas brillantes.
color-burn Oscurece intensamente las áreas oscuras.
difference Resta valores de color, creando contraste fuerte.
exclusion Similar a difference, pero con menor contraste.
hue Aplica el matiz del elemento al fondo.
saturation Aplica la saturación del elemento al fondo.
color Aplica el color del elemento al fondo.
luminosity Aplica la luminosidad del elemento al fondo.

.container {
  background-color: rgba(255, 255, 255, 0.2);
  backdrop-filter: blur(5px);
  mix-blend-mode: plus-lighter;
}

content-visibility

Indica al navegador si el contenido de un elemento debe renderizarse o no al cargar la página. Así, mientras el navegador carga el contenido y lo muestra en pantalla, esta propiedad nos permite indicarle que no cargue el contenido de un elemento hasta que sea necesario. Es similar a la carga diferida, donde los elementos secundarios de un elemento que no está en pantalla no se renderizan hasta que entran en la ventana gráfica.

La principal ventaja de esta función content-visibilityes el rendimiento. Puede acelerar la carga de la página, ya que el navegador puede posponer la visualización de los elementos que no están visibles para el usuario hasta que este se desplace hasta ellos.

content-visibility: [visible | auto | hidden];

Valores Funcion
hidden El elemento omite su contenido (algo similar a aplicarlo display: none;al contenido).
visible No hay ningún efecto y el elemento se renderiza con normalidad. (valor por defecto)
auto Si un elemento se encuentra fuera de la vista principal y navegador determina que el contenido es irrelevante para el usuario lo omite. A medida que el usuario se desplaza hacia el elemento, el navegador dibuja su contenido y la renderización se completa rápidamente.

auto indica al navegador que el contenido de un elemento no es necesario en la carga inicial de la pagina, siempre y cuando este fuera de la pantalla. Sin embargo, el elemento debería seguir estando disponible para el usuario en lugar de ignorarlo por completo en el DOM. Esto significa que el elemento y su contenido deberían poder enfocarse, seleccionarse, navegar por él mediante la tecla Tab y buscarse a través de la función de búsqueda en la página del navegador.

Consideraciones

Naturalmente, cuando un navegador renderiza inicialmente todo el contenido de una página web, conoce la altura necesaria para mostrarlo todo (basándose en la suma de las alturas individuales de todas las secciones de la página) y el desplazamiento será fluido. Sin embargo, content-visibility: auto;cuando se aplica a un elemento, lo trata como si tuviera una altura de 0 (siempre que la heightpropiedad no se haya establecido explícitamente). Cuando el usuario se desplaza y el elemento aparece en la vista (y el navegador comienza a dibujarlo), se calcula la altura real y esto provoca un cambio de diseño en la página. El desplazamiento también puede hacer que la página web se vea un poco irregular, algo conocido como Cambio de Diseño Acumulativo (CLS).

La solución a los grandes cambios de diseño es combinar content-visibility: auto; con contain-intrinsic-size, dándole al navegador una altura predecible para usar como marcador de posición para el elemento cuando lo pinta.

contain-intrinsic-size

Esta propiedad actúa como un marcador de posición para el contenido aún no renderizado, lo que reduce los problemas de desplazamiento y cambio de diseño. Si conoce la altura exacta, puede usarla como valor. De lo contrario, haga una estimación. Al renderizar la sección, si la altura que establece no es la real, se producirá un ligero cambio de diseño, pero no será tan pronunciado como sin esta propiedad.

.container {
  content-visibility: auto;
  contain-intrinsic-size: 4800px;
}
