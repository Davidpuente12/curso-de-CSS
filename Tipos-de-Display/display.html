display

Esta propiedad establece el tipo de visualización de los elementos HTML sin afectar el flujo normal de los elementos. Existen etiquetas que por defecto su display ya está determinado, como la etiqueta <div> que tiene display block, <span> tiene display inline y <button> tiene display inline-block.

Aqui encontraras todos los tipos de visualizacion en elementos HTML Reference type

Tipo Descripcion
Inline Se coloca a continuación del otro (en horizontal). Ignora dimensiones.
block Se coloca encima de otro (en vertical).
inline-block Híbrido en línea-bloque. Actúa como un elemento en línea, pero obedece dimensiones.
flex Contenedor en bloque, similar a block (ocupa todo el ancho del padre).
inline-flex Contenedor en línea, similar a inline-block (ocupa solo el contenido).
grid Utiliza cuadrículas o rejillas con el modelo de cajas Grid CSS.
inline grid La versión en línea (ocupa sólo su contenido) del modelo de cajas Grid CSS.
list-item Actúa como un ítem de una lista. Es el comportamiento de etiquetas como <li>.
table Actúa como una tabla. Es el comportamiento de etiquetas como <table>.
table-cell Actúa como la celda de una tabla. Es el comportamiento de etiquetas como <th> o <td>.
table-row Actúa como la fila de una tabla. Es el comportamiento de etiquetas como <tr>.
contents Ignora la caja del elemento. Útil para mantener Grid/Flex aún teniendo un wrapper intermedio.
none No dibuja en el navegador el contenido del elemento ni sus hijos.

Visualización en bloque

El display block establece que un elemento ocupará todo el espacio disponible por defecto y el siguiente elemento a este se situará por debajo.Es posible añadir medidas de anchura width y altura height a estos a elementos.También es posible agregar todas las propiedades del modelo de caja

Visualización en línea

El display inline establece que un elemento ocupará el espacio del contenido del mismo y el siguiente elemento se situará a la derecha. No es posible añadir medidas de anchura width y altura height a estos a elementos. También, no es posible agregar todas las propiedades del modelo de caja, únicamente funcionará la propiedad margin en el eje horizontal

Visualización de bloque y línea

El display inline-block combina las ventajas de bloque de colocar medidas al elemento y propiedades del modelo de caja correctamente; con las ventajas de inline de colocar un elemento seguido de otro en el mismo espacio. Si el elemento excede el contenido total, se coloca en la siguiente línea por debajo.

Visualización nula

El display none desactiva la visualización de un elemento, como si el elemento no existiera.

Modales

Un “modal” es una ventana emergente que aparece sobre el contenido principal de una aplicación o página web y bloquea la interacción con el resto de la interfaz hasta que el usuario la cierre o complete la acción solicitada. Es muy usado en diseño web y UX para mostrar mensajes importantes, formularios, confirmaciones o alertas

  • Superposición: se muestra encima del contenido existente, oscureciendo o deshabilitando el fondo.
  • Interacción bloqueada: el usuario no puede interactuar con la página hasta cerrar el modal.
  • Propósito claro: se utiliza para acciones críticas como confirmar una operación, mostrar un formulario, o dar información urgente.
  • Cierre controlado: normalmente incluye un botón de cerrar, una “X” en la esquina, o se cierra al hacer clic fuera de la ventana.
