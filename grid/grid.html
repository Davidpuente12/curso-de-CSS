Grid consiste en el ordenamiento de elementos hijos en dos ejes, como si fuera una cuadrícula o tabla. El elemento padre o contenedor deberá contener la propiedad y valor display:"grid" y debes definir las medidas de las columnas y de las filas. A partir de aquí, ya puedes ordenar los hijos según sea necesario.

Valor de display Descripcion
grid Establece una cuadrícula con ítems en bloque, de forma equivalente a block.
inline-grid Establece una cuadrícula con ítems en línea, de forma equivalente a inline-block.

Filas y columnas en grid: la forma principal de definir una cuadrícula es indicar el tamaño de sus filas y sus columnas de forma explícita. Para ello, sólo tenemos que usar las propiedades CSS grid-template-columns y grid-template-rows

Propiedad Valor Descripcion
grid-template-column [colum 1][colum 2] Establece el tamaño de cada columna.
grid-template-rows [fila 1][fila 2] Establece el tamaño de cada fila.
grid-template [rows]/[columns] Propiedad de atajo para filas y columnas.

Valores especiales

Unidad especial fr (fraccion restante) es exclusiva de Grid: representa una fracción del espacio disponible del contenedor. Por ejemplo, 1fr 1fr reparte el espacio en dos partes iguales; al añadir una tercera 1fr, tendrás tres columnas. Con cuatro elementos, se forma un grid dos por dos automáticamente.

min-content Ajusta el ancho de la celda lo mínimo posible sin romper su contenido.

max-content Ajusta el ancho de la celda lo máximo posible para mostrar su contenido.

auto-fill Agrega columnas “fantasma” que rellenan el espacio sobrante del contenedor.

auto-fit Ensancha las columnas para que ocupen todo el espacio del contenedor.

Funcion repeat() se usa en grid para evitar repetir valores, simplificando la definicion de columnas: repeat(3, 1fr) crea tres columnas iguales, seria lo mismo que: 1fr 1fr 1fr.

repeat( veces, tamaño ) = repeat( 4, 1fr )

Funcion minmax() ayuda a declarar el tamaño minimo y maximo para el ancho y alto de una celda, sin depender del contenido que tengamos en ella.

minmax(30px, 300px)

grid-template-column

La propiedad grid-template-columns se usa dentro de un contenedor con display: grid para definir cuántas columnas tendrá la cuadrícula y qué tamaño de ancho ocupará cada una. Valores que usa: (px, %, fr) unidades fijas, relativas o proporcionales.

grid-template-rows

La propiedad grid-template-rows se usa dentro de un contenedor con display: grid para definir cuántas filas tendrá la cuadrícula y qué tamaño de alto ocupará cada una. Valores que usa: (px, %, fr) unidades fijas, relativas o proporcionales.

Formación del grid

Ten en cuenta que el número de columnas o filas que se formaran en el grid dependerá del número de valores que le asignes a estas propiedades. Por ejemplo, si le asignas dos valores, se formarán dos columnas; si le asignas tres valores, se formarán tres columnas y así sucesivamente.

Si quieres crear una cuadrícula de 2x2, con cuatro columnas y cuatro filas, debes asignar cuatro valores a cada propiedad. También puedes usar fracciones: o usar la función repeat.

grid-template-columns: 100px 250px 100px 250px;
grid-template-rows: 250px 100px 250px 100px;
grid-template-columns: 2.5fr 1fr 2.5fr 1fr;
grid-template-rows: 2.5fr 1fr 2.5fr 1fr;
grid-template-columns: repeat(4, 1fr);
grid-template-rows: repeat(4, 1fr);

.content{ display: grid }

.pixeles{
  grid-template-columns: 100px 250px;
  grid-template-rows: 250px 100px;
}

.fracciones{
  grid-template-columns: 2.5fr 1fr;
  grid-template-rows: 2.5fr 1fr;
}

.repeat{
  grid-template-columns: repeat(4, 1fr);
  grid-template-rows: repeat(4, 1fr);
}

Ahora, ten en cuenta que corre de nuestra cuenta vigilar que el número de elementos hijos en el grid es el que debería. Dependiendo del número de elementos hijos que tenga definido el contenedor grid en su HTML, tendremos una cuadrícula de 2x2 elementos (4 ítems), 2x3 elementos (6 ítems), 2x4 elementos (8 ítems) y así sucesivamente.

Propiedades del Grid

A continuación, se muestran otras subpropiedades importantes de Grid:

Propiedad Valor Descripcion
grid-auto-columns [colum 1][colum 2] Establece el tamaño de las columnas que se formen automáticamente al añadir más elementos hijos de los que se han definido en grid-template-columns.
grid-auto-rows [fila 1][fila 2] Establece el tamaño de las filas que se formen automáticamente al añadir más elementos hijos de los que se han definido en grid-template-rows.
grid-auto-flow row | column | dense Establece la dirección en la que se formarán las filas o columnas automáticamente al añadir más elementos hijos de los que se han definido en grid-template-columns o grid-template-rows.
Propiedades para establecer espacios
Propiedad Valor Descripcion
grid-gap [gap filas][gap columnas] Establece el espacio entre filas y columnas, es decir, el espacio entre los elementos hijos del grid. tambien se puede usar solo la palabra gap.
grid-row-gap [gap filas] Establece el espacio entre filas, es decir, el espacio entre los elementos hijos del grid en sentido vertical.
grid-column-gap [gap columnas] Establece el espacio entre columnas, es decir, el espacio entre los elementos hijos del grid en sentido horizontal.

.content {
  display: grid
  grid-template-columns: 100px 150px 200px;
 grid-template-rows: 100px 150px ;
 grid-auto-rows: 150px ;
 grid-auto-flow: column ;
}

Propiedades de Ubicacion

Las propiedades de ubicación en CSS Grid son aquellas que permiten colocar un elemento hijo dentro de la cuadrícula especificando en qué líneas de columna y fila comienza y termina. En otras palabras, controlan la posición y el área que ocupa un ítem dentro del grid.

Propiedad Valor Descripcion
grid-area [nombre] Asigna un nombre a una celda del grid para poder referenciarla posteriormente.
grid-template-areas [area 1][area 2] Define áreas del grid asignándoles un nombre, para poder referenciarlas posteriormente.
grid-column [start]/[end] Define el inicio y el fin de una columna para un elemento hijo del grid, permitiendo que ocupe más de una columna.
grid-row [start]/[end] Define el inicio y el fin de una fila para un elemento hijo del grid, permitiendo que ocupe más de una fila.
grid-column-start [start] Define el inicio de una columna para un elemento hijo del grid.
grid-column-end [end] Define el final de una columna para un elemento hijo del grid.
grid-row-start [start] Define el inicio de una fila para un elemento hijo del grid.
grid-row-end [end] Define el final de una fila para un elemento hijo del grid.

.content {
  display: grid;
  grid-template-columns: 150px 150px 150px;
  grid-template-rows: 75px 75px 75px;
  place-content: center;
}

.item.uno {
  grid-column-start: 1;
  grid-column-end: 4;
}

.item.dos {
  grid-row: 2 / 4;
}

.item.tres {
  grid-area: 2 / 2 / 4 / 4;
}
