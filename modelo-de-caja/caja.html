El modelo de caja se compone de cuatro elementos: margin, border, padding y contenido. Si entras a las herramientas de desarrollador de tu navegador y señalas un elemento HTML, en la sección de estilos te aparecerá una vista parecida a la siguiente imagen, este es el modelo de caja del elemento señalado.

Contenido del elemento HTML

es todo lo que está dentro del elemento. Este tiene medidas establecidas por las propiedades width y height, que representan la anchura y la altura, respectivamente. Si imaginamos una caja, este valor sería todo lo que decidas colocar dentro.

margin

Propiedad define el espacio exterior de un elemento, es decir, la distancia entre ese elemento y los que lo rodean. Es como el "aire" que separa una caja de otras cajas en la página. tiene subpropiedades para definir cada lado por separado, o podemos definir todas los valores en una sola propiedad.

Ejemplo Significado
10px; Todos los lados
10px 20px; 10px arriba/abajo, 20px izquierda/derecha
10px 15px 5px; Arriba, izquierda/derecha, abajo
10px 15px 5px 0; Arriba, derecha, abajo, izquierda (en sentido horario)
auto centra horizontalmente un elemento con ancho definido.
0 Elimina el margen.
% relativo al ancho del contenedor padre.
div { margin-top: 10px ; margin-bottom: 15px ; margin-left: 20px ; margin-right: 10px };

⚠️ Colapso de márgenes verticales Cuando dos elementos tienen márgenes verticales consecutivos, el navegador no los suma, sino que usa el mayor de los dos. Esto se llama colapso de márgenes. al cambiar el display este comportamiento desaparece. Además, en flexbox y grid no ocurre el colapso de márgenes.

🧩 Valores por defecto: el navegador establece valores iniciales a algunas propiedades CSS, este es el caso de margin y padding. Una buena práctica es utilizar el selector universal para restablecer estos valores a 0. ( * margin: 0;padding: 0; )

box-shadow

La propiedad box-shadow se utiliza para añadir sombras alrededor del marco de un elemento, creando la ilusión de profundidad o elevación. Es muy versátil porque permite definir sombras externas o internas, se puede añadir desenfoque, expansion y color.

La sombra se dibuja en relación al caja del elemento (border-box). Si el elemento tiene border-radius, la sombra sigue la misma curva en las esquinas. Se pueden aplicar múltiples sombras separadas por comas, que se apilan en orden (la primera definida queda arriba).

box-shadow: offset-x  offset-y  blur-radius  spread-radius  color  inset;
  • offset-x desplazamiento horizontal de la sombra (positivo = derecha, negativo = izquierda).
  • offset-y desplazamiento vertical (positivo = abajo, negativo = arriba).
  • blur-radius (opcional) controla el desenfoque, cuanto mayor es el valor, mas difusa sera la sombra.
  • spread-radius (opcional) controla la expansion (positivo = sombra mas grande, negativo = mas pequeña).
  • color (opcional) color de la sombra (puede ser con transparencia).
  • inset (opcional) convierte la sombra en interna (dentro del elemento).

border-radius

Se utiliza para redondear las esquinas del borde exterior de un elemento en una página web. Es muy común en botones, tarjetas, imágenes y contenedores para darles un aspecto más suave y moderno. Puede aplicarse con valores en longitud (px, em, rem) o en porcentaje (%).

border-radius: radio (px, em, rem, %)

padding

Define el espacio interno entre el contenido de un elemento y su borde. Es como el "relleno" que empuja el contenido hacia adentro, creando espacio dentro del contenedor. Puedes usar padding con 1 a 4 valores. tiene subpropiedades para definir cada lado por separado, o se pueden definir todos en la propiedad.

div { padding-top: 10px ; padding-bottom: 15px ; padding-left: 20px ; padding-right: 10px };
Ejemplo Significado
10px; Todos los lados
10px 20px; 10px arriba/abajo, 20px izquierda/derecha
10px 15px 5px; Arriba, izquierda/derecha, abajo
10px 15px 5px 0; Arriba, derecha, abajo, izquierda (en sentido horario)

Tamaño total de elementos

El tamaño total del elemento está determinado por la suma de los valores de las propiedades border padding y widtho height, dependiendo del eje. La propiedad margin no está incluida en este cálculo.Por ejemplo, definimos los siguientes estilos:

div { width: 150px ; height: 150px ; padding: 20px ; border: 10px solid gray ; margin: 30px };

box-sizing

Propiedad establece cómo se calculará el width y el height si incluyen bordes y espacios internos. Como buena práctica, se lo coloca en el selector universal, para que todos los elementos sigan esta tendencia. * {box-sizing: border-box;}

Valores Descripcion
content-box (valor por defecto): El ancho y alto sólo incluyen el contenido, excluyendo el padding y el borde. Esto significa que si añades padding o borde, se sumarán al tamaño total del elemento.
border-box El tamaño total del elemento será igual al especificado en el width y height, provocando que las medidas del contenido cambien con respecto a los bordes y espacios internos.

Desbordamiento

si tenemos suficiente contenido en un elemento y hemos forzado el tamaño de ancho y/o alto del elemento para que tenga un tamaño específico (que es más pequeño que su contenido), se va a producir el caso en el que su contenido no tiene suficiente espacio, por lo que se producirá un desbordamiento. Para controlar el comportamiento de este desbordamiento, se utiliza la propiedad overflow.

overflow

controla cómo se maneja el contenido que se desborda del área de un contenedor cuando este no tiene suficiente espacio para mostrarlo. Su función principal es decidir si el contenido extra se muestra, se oculta, se recorta o se desplaza mediante barras de scroll.

Propiedad Valores posibles Descripción
overflow visible | hidden | scroll | auto Control general del desbordamiento en ambos ejes.
overflow-x visible | hidden | scroll | auto Controla el desbordamiento horizontal (eje X).
overflow-y visible | hidden | scroll | auto Controla el desbordamiento vertical (eje Y).
overflow-inline visible | hidden | scroll | auto Controla el desbordamiento en la dirección de escritura (inline).
overflow-block visible | hidden | scroll | auto Controla el desbordamiento en el eje de bloque (block).

Por defecto, el valor inicial es visible, que indica que siempre que ocurra un desbordamiento, el contenido sea visible y aparezca como la imagen anterior. Otras opciones son las siguientes, donde no se permite desbordamiento.

Valor ¿Qué ocurre si se desborda el contenedor? ¿Desbordamiento?
visible Se muestra el contenido que sobresale (comportamiento por defecto). Sí
hidden Se oculta el contenido que sobresale. No
clip Idem a hidden, pero no permite desplazamiento programático. No
scroll Se colocan barras de desplazamiento (horizontales y verticales). No
auto Se colocan barras de desplazamiento (sólo las necesarias). No

#contenedor {
  width: 80%;
  height: 100px;
  overflow-y: hidden; scroll; visible;
}

scroll-snap-type

permite que un contenedor con desplazamiento “encaje” automáticamente en puntos definidos al detener el scroll, creando una experiencia más controlada y fluida. Se aplica al contenedor padre y define la dirección (x, y o ambos) y el nivel de rigidez del ajuste.

  • Controlar cómo el viewport se “ancla” en elementos hijos al desplazarse.
  • Se aplica en el contenedor con scroll (padre).
  • Los elementos hijos deben usar scroll-snap-align para definir su punto de anclaje.
Valor Dirección Comportamiento Ejemplo de uso
none — Desactiva el ajuste automático. scroll-snap-type: none;
x mandatory Horizontal El scroll se detiene obligatoriamente en los puntos de snap. Galería de imágenes horizontal.
x proximity Horizontal El scroll se ajusta solo si el usuario se acerca al punto. Carrusel con desplazamiento suave.
y mandatory Vertical El scroll se detiene obligatoriamente en cada punto de snap. Lista de secciones que encajan al hacer scroll.
y proximity Vertical El scroll se ajusta de forma opcional según cercanía. Lectura de artículos largos.
block mandatory Eje de bloque (según escritura) Encaje obligatorio en dirección de bloque. Diseños multilingües con scroll vertical.
inline proximity Eje de línea (según escritura) Encaje opcional en dirección de línea. Scroll horizontal en idiomas RTL.

scroll-snap-align

Se aplica a los elementos hijos dentro de un contenedor con scroll que tenga definido scroll-snap-type. Su función es indicar cómo debe alinearse el hijo respecto al punto de encaje (snap point) cuando el scroll se detiene.

  • Se aplica en los elementos hijos del contenedor con scroll. el navegador decide cuál encajar según la posición más cercana.
  • Define el punto de referencia del hijo que se usará para el “snap” (inicio, centro o fin)
  • Necesita que el contenedor padre tenga scroll-snap-type configurado.
Valor Descripción Ejemplo de uso
start El inicio del elemento hijo se alinea con el inicio del contenedor. Secciones que comienzan arriba del viewport.
center El centro del elemento hijo se alinea con el centro del contenedor. Carruseles que muestran un ítem centrado.
end El final del elemento hijo se alinea con el final del contenedor. Scroll que encaja al final de cada bloque.
none El elemento no participa en el snap. Elementos secundarios que no deben encajar.

#content {
  overflow-x: scroll;
  scroll-snap-type: x mandatory;
  scroll-behavior: smooth;
}

#content > img {
  width: 375px;
  height: 300px;
  scroll-snap-align: center;
}

scroll-behavior

controla si el desplazamiento dentro de un contenedor (o en la ventana principal) ocurre de manera instantánea o con una animación suave. Es muy útil para mejorar la experiencia de usuario en páginas con enlaces internos o navegación entre secciones. scroll-behavior define cómo se realiza el desplazamiento cuando es provocado por:

  • Navegación con enlaces internos (<a href="#id">).
  • Métodos de JavaScript como element.scrollIntoView() o window.scrollTo().
  • No afecta al desplazamiento manual del usuario (scroll con mouse, teclado o touch).
Valor smooth
auto Desplazamiento inmediato, sin animación (valor por defecto).
smooth Desplazamiento animado y progresivo, creando un efecto visual más agradable.
html {
  scroll-behavior: smooth;
}

Con esto, al hacer clic en un enlace interno, la página se desplazará suavemente hasta la sección indicada.

  • Si se aplica en html, afecta al viewport completo.
  • Si se aplica en un contenedor con overflow, afecta solo a ese contenedor.
